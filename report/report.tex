\section{Introduction}
%──────────────────────────────────────────────────────────────────

Graph Neural Networks (GNNs) are powerful tools for learning from structured data, but they suffer from a fundamental tension: stacking more layers to widen the receptive field leads to oversmoothing and oversquashing, while shallow networks fail to model long-range dependencies~\cite{alon2021on}. This project implements a \textbf{GraphTrans-style} architecture~\cite{wu2022representinglongrangecontextgraph}, a hybrid design that combines a local GNN backbone with a global Transformer.

Our implementation, \textsc{GraphTransLWG}, follows the paper's central design pattern---\texttt{[CLS]}-token readout, reachability-masked global attention, and pre-norm residual blocks---while introducing several implementation-level choices of its own: a custom edge-aware GNN layer, transitive-closure-based attention masking precomputed once per batch, and separate MLP weights for the \texttt{[CLS]} token. We evaluate on the \textsf{NCI} biological benchmarks and \textsf{OGB Code2}, and evaluate a readout ablation for the \texttt{[CLS]} embedding.


%──────────────────────────────────────────────────────────────────
\section{Problem Setup}
%──────────────────────────────────────────────────────────────────

Given a graph $G=(V,E)$ with per-node feature matrix $\mathbf{X}\in\mathbb{R}^{|V|\times d_x}$ and graph-level label $y$, learn $f_\theta(G)\to\hat{y}$ for whole-graph classification or sequence prediction.

\paragraph{Message passing (local bias).}
A standard GNN layer updates node $i$ as
\[
\vec{h}^{(\ell+1)}_i = \phi\!\left(\vec{h}^{(\ell)}_i,\;
  \bigoplus_{j\in\mathcal{N}(i)} \psi\!\left(\vec{h}^{(\ell)}_i,\,\vec{h}^{(\ell)}_j\right)\right),
\]
where $\bigoplus$ is a permutation-invariant aggregation operator. Stacking $k$ such layers gives a receptive field of $k$ hops, but deeper stacks collapse representations---a phenomenon called \emph{oversmoothing}.

\paragraph{Global attention (long-range context).}
Given hidden matrix $\mathbf{H}\in\mathbb{R}^{N\times d}$ for all $N$ nodes, multi-head scaled dot-product attention computes
\[
\mathbf{Q}=\mathbf{H} @ \mathbf{W}_Q^\top,\quad
\mathbf{K}=\mathbf{H} @ \mathbf{W}_K^\top,\quad
\mathbf{V}=\mathbf{H} @ \mathbf{W}_V^\top,\quad
\mathrm{Attn}(\mathbf{H})=\mathrm{softmax}\!\left(\frac{\mathbf{Q} @ \mathbf{K}^\top}{\sqrt{d_h}}+ \mathbf{M}\right) @ \mathbf{V},
\]
where $M$ is an additive attention bias (mask). Without sequence positional encodings, attention is permutation-equivariant over node order; after a graph-level readout such as \texttt{[CLS]}, this gives a permutation-invariant graph prediction. Every node can attend to every reachable node permitted by the mask in a single attention layer, bypassing part of the message-passing depth bottleneck.

%──────────────────────────────────────────────────────────────────
\section{Architecture}
%──────────────────────────────────────────────────────────────────

The \texttt{GraphTransModel} (in \texttt{models/full\_model.py}) consists of:

\begin{enumerate}[leftmargin=1.5em]
  \item \textbf{CLS token injection}: append a \texttt{[CLS]} embedding to the graph (or each graph in the batch), prepare the batch edge index and the CLS mask.
  \item \textbf{Input embedding}: project raw node features to dimension $d$, and use a learnable \texttt{[CLS]} embedding for each CLS node in the batch.
  \item \textbf{Transformer stack}: $L$ transformer blocks, each containing a GNN sublayer, a multi-head attention sublayer, and a feedforward MLP sublayer with pre-norm residuals.
  \item \textbf{Readout}: extract the \texttt{[CLS]} embedding and apply a linear output head (or output heads, in case of \textsf{OGBG Code2})
\end{enumerate}

\subsection{Batch Packing (\texttt{models/batch\_utils.py})}

Before any forward pass, \texttt{pack\_graph\_batch} adds a CLS node to each graph, and then concatenates all graphs in the batch into a single flat vertex tensor and precomputes three structures that are reused across all $L$ transformer layers:

\begin{itemize}
    \item \textbf{\texttt{cls\_mask}}: a boolean vector marking the CLS positions. For a batch of graphs with $[n_1, n_2, \ldots]$ nodes, the CLS of graph $i$ sits at index $\sum_{j<i}(n_j+1) + n_i$.
    \item \textbf{\texttt{edge\_index}}: packed, offset-corrected edge list for the whole batch.
    \item \textbf{\texttt{attn\_factors}}: the \emph{transitive closure} of the adjacency matrix (plus CLS connections), computed via fixed-point iteration initialised from the identity matrix $\mathbf{I}$: $\mathbf{A}^* \leftarrow \mathrm{clamp}(\mathbf{A}^*\cdot \mathbf{A}, 1)$ until convergence. Entry $(i,j)=1$ iff node $j$ is reachable from node $i$ in zero or more hops (within the same graph); cross-graph entries remain 0. Its log is passed as an additive bias to \texttt{scaled\_dot\_product\_attention}, driving unreachable pairs to $-\infty$.
    \begin{itemize}
        \item It the parameter \texttt{attn\_factors} is set (as in not \texttt{None}), the entries in $\mathbf{A}$ are weighed by the distance factor, to prioritize attention to nearby nodes. That is, the update step becomes $\mathbf{A}^*_{n} \leftarrow \mathrm{clamp}(\max (f_{n}\mathbf{A}^*_{n-1}\cdot \mathbf{A},\  \mathbf{A}^*_{n-1}),\ 1)$, and this is repeated till convergence, with $f_{n} = 0$ for out-of-range indices.
    \end{itemize}
\end{itemize}

Precomputing once and caching as a \texttt{PackedGraphBatch} dataclass eliminates expensive per-layer reachability computation in Python.

\subsection{Input Embedding (\texttt{models/full\_model.py})}

For graph classification datasets (\textsf{NCI1}, \textsf{NCI109}, \textsf{OGBG Molpcba}), a single linear layer maps raw node features $\vec{x}_v \in \mathbb{R}^{d_x}$ to $\vec{h}^{(0)}_v \in \mathbb{R}^d$:
\[
\vec{h}^{(0)}_v =\mathbf{W}_\text{in}\,\vec{x}_v.
\]

For \textsf{OGBG Code2} (Abstract Syntax Trees), node features consist of a discrete node type, a discrete attribute index, and an integer depth. The \texttt{ASTNodeEncoder} module therefore uses three separate embedding tables (type, attribute, depth) and sums their outputs:
\[
\vec{h}^{(0)}_v
  = E_\text{type}[x_{v,0}]
  + E_\text{attr}[x_{v,1}]
  + E_\text{depth}[\min(\delta_v, d_\text{max})],
\]
where $\delta_v$ is the node's depth in the AST, clipped at $d_\text{max}=20$.
For Code2, the dataset transform also augments the AST edge set with inverse edges and next-token edges before graph packing.

The \texttt{[CLS]} token is represented by a learned linear map applied to a fixed ones vector---effectively a learnable bias vector of dimension $d$---with one CLS token appended \emph{after} the node block of each graph in the packed batch.

\subsection{Transformer Block (\texttt{models/transformer.py})}

Each of the $L$ transformer blocks is a \texttt{TransformerLayer} that applies three sublayers with pre-norm residuals:
\[
\mathbf{H} \leftarrow \mathbf{H} + \mathrm{Drop}\!\left(\mathrm{GNN}(\mathrm{LN}(\mathbf{H}))\right)
\]
\[
\mathbf{H} \leftarrow \mathbf{H} + \mathrm{Drop}\!\left(\mathrm{Attn}(\mathrm{LN}(\mathbf{H}))\right)
\]
\[
\mathbf{H} \leftarrow \mathbf{H} + \mathrm{Drop}\!\left(\mathrm{MLP}(\mathrm{LN}(\mathbf{H}))\right)
\]
where $\mathbf{H} \in \mathbb{R}^{(N+B)\times d}$ holds all node and CLS embeddings for a batch of $B$ graphs with $N$ total nodes.

\subsection{GNN Sublayer (\texttt{models/gnn.py})}

Each \texttt{GNNLayer} is a custom \emph{edge-aware message-passing} step that operates \textbf{only on non-CLS nodes}; CLS positions receive zero output and rely on the residual to carry their values forward. The computation for node $u$ is:

\begin{align*}
\vec{\tilde{h}}_u\ &=\ \vec{h}_u @ \mathbf{W}_1^\top & &\text{(node transform)} \\
\vec{e}_{uv}\ &=\ [\vec{\tilde{h}}_u \,\|\, \vec{\tilde{h}}_v] @ \mathbf{W}_2^\top & &\text{(edge embedding from pair)} \\
\vec{m}_u\ &=\ \textstyle\sum_{v\in\mathcal{N}(u)} \vec{\tilde{h}}_v & &\text{(sum of neighbour transforms)} \\
\vec{n}_u\ &=\ \textstyle\sum_{v\in\mathcal{N}(u)} \vec{e}_{uv} & &\text{(sum of edge embeddings)} \\
\vec{h}'_u\ &=\ \mathrm{GELU}\!\left([\vec{\tilde{h}}_u \,\|\, \vec{m}_u \,\|\, \vec{n}_u]\right) @ \mathbf{W}_3^\top & &\text{(aggregate \& project)}
\end{align*}

Stacking $K$ such layers inside one transformer block gives a $K$-hop local context before attention, following the packed edge orientation used by the implementation.

\subsection{Attention Sublayer (\texttt{models/attention.py})}

Multi-head scaled dot-product attention is applied to \emph{all} tokens (nodes + CLS):
\[
a^\ell_{ij} = \frac{\left(\vec{h}_i @ \mathbf{W}_Q^{\ell\top}\right)\left(\vec{h}_j^\top @ \mathbf{W}_K^{\ell\top}\right)}{\sqrt{d_h}},
\qquad
\tilde{a}^\ell_{ij} = a^\ell_{ij} + \log A^*_{ij},
\qquad
\vec{h}'_i = \sum_j \mathrm{softmax}_j(\tilde{a}^\ell_{i\cdot}) \vec{h}_j @ \mathbf{W}_V^{\ell\top},
\]
where $A^*_{ij} \in [0,1]$ is the precomputed reachability entry. Because $\log 0 = -\infty$, unreachable pairs are effectively masked out. The CLS token is bidirectionally connected to every node in its graph (set explicitly in \texttt{pack\_graph\_batch}), so it can attend to---and be attended by---all nodes. Cross-graph attention is prevented by the block-diagonal structure of $\mathbf{A}^*$.
The multi-head outputs are concatenated and passed through a final linear output projection.

\paragraph{Optional distance-weighted attention.}
The config parameter \texttt{attn\_distance\_factors} (a list of per-hop scale factors) allows replacing the binary reachability mask with a soft, distance-decayed version: nodes $k$ hops away contribute with factor $f_k$. In our experiments this is set to \texttt{None}, giving binary transitive-closure reachability with no distance decay.

\subsection{MLP Sublayer (\texttt{models/mlp.py})}

A position-wise two-layer feedforward network with GELU activation is applied after attention. A key implementation detail: the \texttt{MLP} module maintains \textbf{two independent sets of weights}---\texttt{layers} for regular nodes and \texttt{layers\_cls} for the CLS token. This lets the model learn different transformations for the graph-summary token versus per-node representations, without coupling their learning dynamics.

\subsection{Output Head}

After $L$ transformer blocks, the CLS embedding $\vec{h}_\text{cls} \in \mathbb{R}^d$ is extracted and passed through the output head:
\begin{itemize}
  \item \emph{Classification} (\textsf{NCI}, \textsf{OGBG MolPCBA}): $\hat{y} = \mathbf{W}_\text{out}\,\vec{h}_\text{cls}$, $\mathbf{W}_\text{out}\!\in\!\mathbb{R}^{d \times C}$.
  \item \emph{Sequence prediction} (\textsf{OGBG Code2}): $\hat{y}_t = \mathbf{W}^{(t)}_\text{out}\,\vec{h}_\text{cls}$ for $t = 1,\ldots, T_\text{max}$, using $T_\text{max}$ independent linear heads.
\end{itemize}

%──────────────────────────────────────────────────────────────────
\section{Training Objective and Optimization (\texttt{models/train.py})}
%──────────────────────────────────────────────────────────────────

\paragraph{Loss.}
For graph classification with batch size $B$:
\[
\mathcal{L}(\theta) = \frac{1}{B}\sum_{g=1}^{B} \mathrm{CE}(f_\theta(G_g), y_g).
\]
For Code2, cross-entropy is averaged over all sequence positions:
\[
\mathcal{L}(\theta) = \frac{1}{B\cdot T}\sum_{g=1}^{B}\sum_{t=1}^{T} \mathrm{CE}(\hat{y}^{(g)}_t, y^{(g)}_t).
\]

\paragraph{Optimizer and scheduler.}
All experiments use Adam with $(\beta_1,\beta_2) = (0.9, 0.999)$. A cosine-annealing LR schedule (\texttt{CosineAnnealingLR}) with $T_\text{max} = $ \#epochs is applied unless disabled. During training, the best model state by validation metric is kept in memory and restored before reporting test results; \texttt{main.py} then saves checkpoints to disk.

\paragraph{Multi-run protocol.}
\texttt{run\_graph\_transformer\_experiments} trains $R$ independent runs with different seeds. Final results are reported as mean $\pm$ std of test metrics across runs. Exact reproducibility can still depend on hardware backend and nondeterministic PyTorch/CUDA kernels.

\subsection{FLAG Adversarial Training (\texttt{trainers/flag\_trainer.py})}

The repository contains a FLAG~\cite{kong2021flag} trainer, which augments training by injecting adversarial perturbations $\delta$ into node embeddings, computed via $m$ projected gradient steps:
\[
\delta^{t+1} = \Pi_{\|\cdot\|_\infty \leq \epsilon}\!\left(\delta^t + \alpha\,\mathrm{sign}(\nabla_\delta \mathcal{L}(\theta,\delta^t))\right),
\]
with step size $\alpha$ (default $8\times10^{-3}$) and $m=3$ steps. However, this trainer is not used by the current \texttt{models/train.py} GraphTransLWG training loop, and it expects a model interface with an explicit perturbation input. We therefore treat it as auxiliary repository code rather than part of the main reported experiments.

\subsection{Ablation: Effectiveness of \texttt{[CLS]} Embedding on \textsf{NCI1}}

\paragraph{Setup.}
We perform an ablation study on different Transformer readout strategies to analyze how graph-level representations should be extracted from the output token sequence. The compared readout strategies are:
(1)~\textbf{mean}: average all node (non-CLS) output embeddings to obtain one graph embedding;
(2)~\textbf{last}: use the last output embedding as the graph embedding;
(3)~\textbf{\texttt{[CLS]}}: append a learnable \texttt{[CLS]} token and use its final embedding as the graph representation;
and (4)~\textbf{\texttt{[CLS]}, cat}: concatenate the final \texttt{[CLS]} embedding with the mean of the final node embeddings before prediction.

This ablation evaluates whether a dedicated graph-summary token can aggregate graph-level information more effectively than standard pooling operations.

\paragraph{\textsc{GraphTransLWG} setup.}
The experiments are conducted on the \textsf{NCI1} dataset using our \textsc{GraphTransLWG} architecture. Each configuration was evaluated across multiple random seeds, and we report the mean and standard deviation of the test accuracy.

\end{table}

The quantitative results show that the vanilla \texttt{[CLS]} readout performs worse than the alternative aggregation strategies, achieving only $79.72\%$ test accuracy. In contrast, both mean pooling and last-token pooling achieve comparable performance above $81.5\%$. The best result is obtained using the concatenated \texttt{[CLS]} variant, which achieves $81.67\%$ test accuracy.

These observations suggest that while a standalone \texttt{[CLS]} token may not sufficiently capture graph-level structure in \textsc{GraphTransLWG}, augmenting it with a pooled node-level summary significantly improves representation quality. Overall, the \texttt{[CLS]}, cat strategy provides the most effective graph-level aggregation among the evaluated methods.


%──────────────────────────────────────────────────────────────────
\section{Conclusion}
%──────────────────────────────────────────────────────────────────

We implemented \textsc{GraphTransLWG}, a GraphTrans-style architecture~\cite{wu2022representinglongrangecontextgraph} with several implementation-level contributions: (i) a custom edge-aware GNN layer that incorporates pairwise edge embeddings alongside neighbour aggregation; (ii) transitive-closure-based attention masking precomputed once per batch and reused across all $L$ transformer blocks; (iii) separate MLP weights for the \texttt{[CLS]} token; and (iv) a pre-norm residual structure throughout. Experiments on \textsf{NCI1}, \textsf{NCI109}, and \textsf{OGB Code2} compare our implementation against standard baselines, while the readout ablation (Table~\ref{tab:ablation}) evaluates how different graph-summary strategies affect \textsc{GraphTransLWG}.
